The previous explicit dev pin for `react-server-dom-webpack 19.3.0` is superseded: it is affected by [GHSA-xqc2-xf4c-x3h3](https://github.com/advisories/GHSA-xqc2-xf4c-x3h3). The app has no server-components feature or server endpoint. Router and Jest expose the package as an optional peer, and the test helper loads it only for server-component rendering. Its patched 19.3.1 release requires newer React/React DOM peers, so upgrading the native React runtime solely for unused tooling is avoided. Remove the unused direct dev pin and regenerate the lockfile from the manifest in an isolated directory; this removes npm's retained optional renderer and deduplicates/refreshes allowed transitive versions. Exact `npm ci`, app/storage tests and exports verify that the app does not require that optional feature. Future server-components work must explicitly choose a patched, compatible renderer.

Clean resolution reports 22 moderate findings and zero low/high/critical. The high/critical audit gate and SDK check remain enabled with no exclusions or overrides. This is a dependency remediation, not a data migration; workout schema and backup format are unchanged.

The audit baseline remains 31 findings (1 low, 30 moderate), zero high/critical; thresholds are unchanged.
