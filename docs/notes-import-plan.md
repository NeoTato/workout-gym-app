# Paste workout notes

Offline parser and review flow, entered after workout date/location setup. One exercise per nonblank line, supporting explicit lb/lbs/kg/plates × whole reps and bodyweight reps. Subsequent weighted sets on the same line may inherit an explicit unit, with a visible review warning. Units never carry across exercises. Unsupported or partially parsed lines cannot silently import: edit the original text or explicitly exclude those lines. Mixed units on a line require splitting into separate exercises; there is no automatic conversion.

Review shows source text, detected sets, inferred-unit warnings and exercise identity. Suggest compatible saved names; choosing one copies its identity/categories but not equipment or measurements. No fuzzy auto-linking. New exercises remain uncategorized for normal editor setup. Import appends uniquely identified completed sets to the current draft, never overwrites existing exercises or writes completed history. Date/location come from the existing setup flow. Normal editor supports corrections before Finish workout. Input bounds: 20,000 characters, 100 nonblank lines, 50 sets per exercise.

Verification: exact user example, decimals and unit spacing/case, inheritance, unknown/mixed units, partial input, invalid numbers, duplicate lines/IDs, matching compatibility, review/exclusion/acknowledgment and append behavior. Types, lint, complete Jest suite, SQLite suite and exports before review. No AI service, network call, dependency or database migration. Delivery through a separate draft PR; no automatic merge or APK rebuild.
